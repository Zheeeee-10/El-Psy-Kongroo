# El-Psy-Kongroo

个人学习仓库，记录我从零开始学 GitHub 的过程。

**在线主页 → https://zheeeee-10.github.io/El-Psy-Kongroo/**

## 关于

这个仓库本身就是练习场。从注册账号到 GitHub Pages 上线，每一步都是真在这上面走完的：
建分支、提 Pull Request、开 Issue、用 `Fixes #N` 自动关闭。

学习进度和日常笔记都在上面的主页里更新。README 只保留项目本身的说明，
避免同一份内容维护两遍。
